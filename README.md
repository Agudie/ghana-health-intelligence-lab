# ghana-health-intelligence-lab
This repository documents my learning journey in Python, data science, machine learning and artificial intelligence, with a focus on public health applications in Ghana and Africa.

**Learning Objectives**
- Develop Python programming skills.
- Learn data manipulation and cleaning using Pandas.
- Understand public health datasets.
- Understand machine learning applications in healthcare.
- Investigate health data quality, equity and disease surveillance.

**Learning Roadmap**
- Phase 1: Python and data science foundations.
- Phase 2: Data analysis and visualisation.
- Phase 3: Machine learning foundations.
- Phase 4: Applied public health research and AI.

**Repository Structure**
Notebooks, datasets documentation and learning logs will be organised as the project develops.
